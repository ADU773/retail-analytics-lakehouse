## Method notes

- Revenue = net revenue (list price x quantity - discounts), excluding shipping and cancelled orders.
- Attribution = last touch: the traffic source of the session containing the purchase event.
- RFM scores are quintiles as of the as-of date; segments use the classic R x F map.
- CLV = BG/NBD expected purchases (52 weeks) x Gamma-Gamma expected order value x the customer's historical gross-margin rate. The backtest refits the model on data up to 26 weeks before the as-of date.
